# Symbole ohne Text – zur Prüfung durch dich

Diese Bedienelemente zeigen nur ein Symbol. Alle haben einen Namen für VoiceOver (in der rechten Spalte); umbenannt habe ich nichts. Bitte sag, welche du eindeutiger haben willst (Text daneben, anderes Symbol oder anderer Name).

| Wo | Symbol (Aussehen) | Name für VoiceOver | Selbsterklärend? |
|---|---|---|---|
| Übersicht | Lupe | Alle Einträge durchsuchen | ja |
| Übersicht | Plus | Neuer Eintrag | ja |
| Übersicht, Heute, Skill | Play-Dreieck im Kreis | „<Titel> starten“ / Timer starten | wahrscheinlich |
| Heute, To-dos, Gewohnheiten | Kreis zum Abhaken | Titel des Eintrags (Schalter) | ja |
| To-dos | Lupe | To-dos durchsuchen | ja |
| To-dos | Listensymbol | Listen bearbeiten | **unklar** |
| To-dos | Plus im Kreis | Liste hinzufügen | mittel |
| Gewohnheiten | Plus | Neue Gewohnheit | ja |
| Stück, Abschnitt | drei Punkte „···“ | Mehr zu den Aufnahmen | mittel |
| Wiedergabeleiste (Würfel) | Pfeil zum Anfang / Pfeil links / Pfeil rechts / Play / Pfeil zum Ende | Zum Anfang / Ein Zug zurück / Ein Zug weiter / Abspielen / Zum Ende | ja (wie Media-Player) |
| Würfel-Trainer | Uhr | Zeiten | mittel |
| Würfel-Trainer | Buch | Anleitung | mittel |
| Würfel-Trainer | Tastatur | Züge eingeben | ja |
| Würfel-Trainer | zwei Pfeile im Kreis | Ansicht zurücksetzen | **unklar** |
| Würfel-Trainer, Wiedergabe | X | Wiedergabe beenden | ja |
| Wunschliste, Begriffe | Kreis zum Abhaken | „Metronom gekauft“ / „Doomsday verstanden“ | ja |
| Flaggen-Trainer | vier Kacheln (Raster) | Fortschritt | **unklar** |
| Flaggen-Trainer | Schieberegler | Einstellungen | mittel |

Die vollständige, automatisch erzeugte Liste steht nach jedem Lauf von `npm run test:e2e` (Suite `a11y`) in `test-results/symbole.md`.
